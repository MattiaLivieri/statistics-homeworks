Statistical Independence

Contingency tables and Pearson’s chi-square test

1. What independence means

In probability: X and F are independent if P(X ∈ A, F ∈ B) = P(X ∈ A) P(F ∈ B) for all measurable sets A and B. For categorical variables, it is enough to check every category pair:

P(X = xi, F = fj) = P(X = xi) P(F = fj).

Equivalently, knowing the category of X leaves the distribution of F unchanged: P(F = fj | X = xi) = P(F = fj) whenever the conditioning event has positive probability.

In statistics: exact independence in the sample would mean that every observed cell proportion equals the product of its two marginal proportions. Even when the variables are independent in the population, sample proportions can differ from those products by chance. Pearson’s chi-square test assesses whether the observed differences are unusually large under independence.

2. Contingency table and frequencies

The worked example uses 100 synthetic paired observations: X is study method (practice quizzes or reading notes), and F is exam result (pass or fail). The program adds one to the cell for each observed (X, F) pair.

3. Expected frequencies and chi-square

Null hypothesis: X and F are independent. Alternative: they are dependent. Under the null, multiply the two estimated marginal probabilities and scale by N to obtain a fitted expected count:

Eij = N (Ri/N)(Cj/N) = RiCj/N.

For a table with r rows and c columns, compute Pearson’s statistic without a continuity correction:

χ² = ∑i,j (Oij − Eij)²/Eij,   df = (r − 1)(c − 1).

Assuming independent observations, compare χ² with the 95th percentile of the chi-square distribution for those degrees of freedom. Reject the null if the statistic exceeds that cutoff. As a conservative rule for the large-sample approximation, the program makes a test decision only if each expected count is at least 5.

Interpretation of the worked example

The expected pass count in the practice-quiz group is 50 × 55 / 100 = 27.5, compared with 35 observed passes. In both rows, the observed pass and fail counts differ from their expected values by 7.5 in magnitude. Thus χ² = 2[(7.5²/27.5) + (7.5²/22.5)] ≈ 9.0909. With one degree of freedom this exceeds 3.8415.

The pass rates are 70% for practice quizzes and 40% for reading notes, compared with 55% overall. The test rejects independence for these example data under the assumed sampling model. The dataset is synthetic, so this illustrates the interpretation without drawing an inference about real students.

Association and causality: the comparison does not establish that the study method caused the difference in pass rates. In an observational study, prior preparation or study time could influence both method choice and the exam result. A causal claim would require a suitable design, such as random assignment, or justified causal assumptions.

View the JavaScript calculation
function analyze(pairs, maxCells = Infinity) {
  const N = pairs.length;
  if (!N) throw new Error('Enter at least one paired observation.');
  const xLevels = [...new Set(pairs.map(([x]) => x))];
  const fLevels = [...new Set(pairs.map(([, f]) => f))];
  const r = xLevels.length, c = fLevels.length;
  if (r * c > maxCells) throw new Error('The table has more than ' + maxCells.toLocaleString('en-US') + ' cells. Use fewer categories.');
  const rowIndex = new Map(xLevels.map((x, i) => [x, i]));
  const colIndex = new Map(fLevels.map((f, j) => [f, j]));
  const observed = Array.from({ length: r }, () => Array(c).fill(0));
  const rowTotals = Array(r).fill(0), colTotals = Array(c).fill(0);
  for (const [x, f] of pairs) {
    const i = rowIndex.get(x), j = colIndex.get(f);
    observed[i][j]++;
    rowTotals[i]++;
    colTotals[j]++;
  }

  const marginalX = rowTotals.map(total => total / N);
  const marginalF = colTotals.map(total => total / N);
  const fGivenX = observed.map((row, i) => row.map(count => count / rowTotals[i]));
  const xGivenF = observed.map(row => row.map((count, j) => count / colTotals[j]));
  const expected = rowTotals.map(ri => colTotals.map(cj => ri * cj / N));
  let chiSquare = 0, minExpected = Infinity;
  for (let i = 0; i < r; i++) {
    for (let j = 0; j < c; j++) {
      const e = expected[i][j];
      chiSquare += (observed[i][j] - e) ** 2 / e;
      minExpected = Math.min(minExpected, e);
    }
  }
  const df = (r - 1) * (c - 1);
  const critical = df > 0 && minExpected >= 5 ? criticalValue(df) : null;
  const decision = df === 0 ? 'degenerate' : critical === null ? 'sparse' :
    chiSquare > critical ? 'reject' : 'fail-to-reject';
  return { N, xLevels, fLevels, observed, rowTotals, colTotals, marginalX, marginalF,
    fGivenX, xGivenF, expected, chiSquare, df, minExpected, critical, decision };
}

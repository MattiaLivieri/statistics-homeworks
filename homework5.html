Numerical Integration and the Normal CDF

Domain and range partitions, followed by a stable computation of normal probabilities.

1. Riemann and Lebesgue integration

Domain and range partitions

The domain method divides [a, b] into N equal subintervals and evaluates f at each midpoint:

h = (b − a)/N,   RN = h ∑i=0N−1 f(a + (i + ½)h).

The range method divides the values into bins Bj = [yj, yj+1), including the maximum in the last bin. For each bin, it finds the Lebesgue measure λ(Ej) of its preimage Ej = {x : f(x) ∈ Bj}. Replacing f on that set by the bin midpoint gives the integral of a simple function:

LK = ∑j=0K−1 [(yj + yj+1)/2] λ(Ej).

For bounded measurable f and bins of width Δy, the pointwise error is at most Δy/2, so |LK − ∫ f| ≤ (b − a)Δy/2. The implementation obtains the measures from the formulas below, rather than counting sample points inside bins. When a value occurs on a set of positive measure, we can use that value as an exact singleton bin.

An unbounded function and two exceptional cases

Unbounded integrand. The value 2 for 1/√x is both its improper Riemann integral and its Lebesgue integral; the function is not bounded, so the proper Riemann integral does not apply. The domain rule uses interior midpoints. In the range rule we cap the function at T = 1 + √K, use K bins on [1, T), and add the cap atom T · T−2 exactly. The cap removes ∫01/T²(x−1/2 − T) dx = 1/T. Together with the bin error, this gives a total bound of 1/T + (T − 1)/(2K), which tends to zero.

Dirichlet. Every nonempty subinterval has rational and irrational points, so the lower and upper Darboux sums are 0 and 1. The uniform midpoint tags (2i + 1)/(2N) are rational and give 1 for every N. Tags (i + √2/2)/N are irrational and give 0 instead. There is no Riemann integral. The Lebesgue integral is 0 because the rationals form a countable set of measure zero.

Thomae. At an irrational point the function is continuous: for every ε > 0, only finitely many fractions in [0, 1] have reduced denominator small enough to give f ≥ ε. Discontinuities occur only at rationals, so Thomae is Riemann integrable by the Lebesgue criterion. Both integrals are 0. To evaluate its midpoints, the program uses the exact numerator and denominator and reduces the fraction with a greatest common divisor. Testing whether a floating-point number is rational would not distinguish the mathematical tags.

For sin(x) and x2, the observed orders on the last two refinements are 2.00 and 2.00 for the domain rule, and 1.50 and 1.50 for the range rule. An order p means that the error decreases roughly as N−p. The range measures have a derivative singularity at an endpoint, whereas the original integrands are smooth. The step’s midpoint error is 1/N for odd N and zero for even N; its range sum is exact at every size. For the cusp, the range bins have constant mass per unit of value, so their midpoint sum is exact. The domain error for odd N is 1/(4N2).

For 1/√x, the observed orders are 0.50 (domain) and 0.49 (range). In the domain rule the first cell alone has error (2 − √2)/√N, and the errors on the other cells are bounded in total by h[f(h) − f(1)] ≤ √h. Thomae’s rational midpoint sums tend to zero, with errors that depend on the denominators of the grid tags. Both rules have the same limit for every bounded Riemann-integrable example. The singular example has equal improper and Lebesgue integrals, while Dirichlet has only a Lebesgue integral.

Both partition loops use constant working memory. The domain loop uses N terms; Thomae adds a gcd calculation per tag. The range loop reuses each bin’s right boundary as the next left boundary and uses K boundary evaluations when the initial boundary is known. With known level-set measures, the step and the two pathological cases need constant work. For a general integrand, computing preimage measures can be harder than evaluating f. The speed and accuracy in this experiment therefore depend on which information about the function is available.

JavaScript for the domain and range rules
function gcd(a, b) {
  while (b) [a, b] = [b, a % b];
  return a;
}

function domainMidpoint(spec, n) {
  const dx = spec.end / n;
  let sum = 0, correction = 0;
  for (let i = 0; i < n; i++) {
    let v;
    if (spec.id === 'dirichlet') v = 1; // (2i+1)/(2n) is exactly rational.
    else if (spec.id === 'thomae') v = gcd(2 * i + 1, 2 * n) / (2 * n);
    else if (spec.id === 'step') v = 2 * i + 1 < n ? 1 : 3;
    else v = spec.f((i + .5) * dx);
    const term = v - correction, next = sum + term;
    correction = (next - sum) - term;
    sum = next;
  }
  return sum * dx;
}

function rangePartition(spec, k) {
  if (spec.atoms) {
    let value = 0;
    for (const [level, measure] of spec.atoms) value += level * measure;
    return value;
  }
  if (spec.id === 'singular') {
    const cap = 1 + Math.sqrt(k), dy = (cap - 1) / k;
    let previous = 1, sum = 1 / cap, correction = 0; // Exact atom at the cap.
    for (let j = 0; j < k; j++) {
      const right = j === k - 1 ? cap : 1 + (j + 1) * dy;
      const next = 1 / (right * right);
      const term = (1 + (j + .5) * dy) * (previous - next) - correction;
      const total = sum + term;
      correction = (total - sum) - term;
      sum = total;
      previous = next;
    }
    return sum;
  }
  const dy = spec.ymax / k;
  let previous = 0, sum = 0, correction = 0;
  for (let j = 0; j < k; j++) {
    const edge = j === k - 1 ? spec.ymax : (j + 1) * dy;
    const next = spec.below(edge);
    const term = (j + .5) * dy * (next - previous) - correction;
    const total = sum + term;
    correction = (total - sum) - term;
    sum = total;
    previous = next;
  }
  return sum;
}

2. Numerical computation of the normal CDF

For a standard normal random variable, the density is φ(t) = e−t²/2/√(2π), and Φ(z) = ∫−∞z φ(t) dt. The definition and symmetry are described in the supplied ETSU notes.

Why elementary functions do not suffice

Let u = e−x²/2, so u′ = −xu. This exponential is transcendental over the rational functions in x: in any polynomial relation, divide out the lowest power of u and let x tend to +∞. A nonzero rational coefficient cannot be canceled by exponentially decreasing terms.

Apply Liouville’s theorem on elementary antiderivatives to the differential field ℂ(x, u). If u had an elementary primitive in an extension with the same constants, the theorem would express u as a derivative v′ plus constant multiples of logarithmic derivatives wj′/wj, with v and wj rational in x and u. In a Laurent expansion at u = ∞, a nonzero rational wj has a leading term A(x)ud. Its logarithmic derivative has leading part A′/A − dx and no positive powers of u. Therefore the coefficient of u on the right must come from v′. If R(x) is the coefficient of u in v, it must satisfy

R′(x) − xR(x) = 1.

A finite pole of R would give a higher-order pole in R′ than in xR, so no finite poles are possible. Then R must be a polynomial. If it is nonzero, −xR has strictly higher degree than R′, so the left side cannot be the constant 1. The zero polynomial also fails. Thus the Gaussian density has no elementary antiderivative. Since Φ′ = φ, the normal CDF is non-elementary as well.

An exact representation with a special function

The error function is defined by erf(u) = (2/√π) ∫0u e−s² ds. By symmetry of φ and the change of variable s = t/√2,

Φ(z) = ½[1 + erf(z/√2)],   Q(a) = Φ(−a) = ½ erfc(a/√2),   a ≥ 0,

where erfc(u) = 1 − erf(u). These identities are exact. A call to erf or erfc still requires a numerical algorithm to return digits; the identities specify the function being evaluated.

Chosen algorithm: 32-node Gauss–Legendre quadrature

Compute the smaller tail directly. For a = |z|, shift the integration variable by a and factor out the density at that point:

Q(a) = φ(a) J(a),   J(a) = ∫0∞ e−at−t²/2 dt.

Truncate at T = 80/(√(a2 + 80) + a), which satisfies aT + T2/2 = 40. Beyond T, the omitted integral is at most e−40/(a + T). On [0, 1/(a + 1)], the integrand is at least e−1, so the relative truncation error is at most e−39(a + 1)/(a + T) ≤ e−39√(81/80) < 1.2 × 10−17. This bound covers truncation; the numerical comparison below includes quadrature and rounding error.

Map the 32 Gauss–Legendre nodes ξi on [−1, 1] to ti = (T/2)(1 + ξi) on [0, T]. The nodes and weights wi are computed once and reused:

Q(a) ≈ φ(a)(T/2) ∑i=132 wi e−atᵢ−tᵢ²/2.

Return Q(a) for negative z, 1 − Q(a) for positive z, and ½ at zero. Computing the lower tail directly avoids cancellation there. For large positive z, the CDF can round to 1 in binary64; the small tail itself can still be computed separately. For a ≥ 39 the upper bound φ(a)/a is below half the smallest positive binary64 value, so the tail rounds to zero.

Alternative methods and their cost

Composite Simpson. Integrate the same scaled integrand over [0, T] with an even number M of panels. The code combines endpoints and interior values with weights 1, 4, 2, …, 4, 1, then multiplies by T/(3M). At z = −5, the observed order between 128 and 512 panels is 4.00, close to the fourth-order convergence expected for this smooth integrand.

Series for erf. Termwise integration of the exponential series gives

erf(u) = (2/√π) ∑k=0∞ (−1)ku2k+1 / [k!(2k + 1)].

The implementation updates each term from the preceding term, so it needs neither powers nor factorials at every iteration. It uses this series for |z| ≤ 2 and stops once the term magnitude is at most 10−17. For large arguments, alternating terms can be large before they decay, and forming a small CDF by subtracting nearly equal quantities loses precision. Direct tail integration avoids that problem.

JavaScript for the normal CDF methods
function legendrePair(n, x) {
  let p0 = 1, p1 = x;
  for (let j = 2; j <= n; j++) {
    const p = ((2 * j - 1) * x * p1 - (j - 1) * p0) / j;
    p0 = p1;
    p1 = p;
  }
  return [p1, n * (p0 - x * p1) / (1 - x * x)];
}

function gaussLegendre(n) {
  const nodes = new Float64Array(n), weights = new Float64Array(n);
  for (let i = 0; i < n / 2; i++) {
    let x = Math.cos(Math.PI * (i + .75) / (n + .5));
    for (let j = 0; j < 30; j++) {
      const [p, dp] = legendrePair(n, x), next = x - p / dp;
      const change = Math.abs(next - x);
      x = next;
      if (change <= Number.EPSILON) break;
    }
    const [, dp] = legendrePair(n, x), w = 2 / ((1 - x * x) * dp * dp);
    nodes[i] = -x;
    nodes[n - 1 - i] = x;
    weights[i] = weights[n - 1 - i] = w;
  }
  return { nodes, weights };
}

const GL32 = gaussLegendre(32);
const inverseSqrt2Pi = 1 / Math.sqrt(2 * Math.PI);
const cut = a => 80 / (Math.sqrt(a * a + 80) + a);
const scaledDensity = (a, t) => Math.exp(-t * (a + t / 2));
const density = a => inverseSqrt2Pi * Math.exp(-a * a / 2);

function tailGauss(a) {
  if (a === 0) return .5;
  if (a >= 39) return 0; // Below half the smallest positive binary64 number.
  const h = cut(a) / 2;
  let sum = 0;
  for (let i = 0; i < 32; i++) {
    const t = h * (1 + GL32.nodes[i]);
    sum += GL32.weights[i] * scaledDensity(a, t);
  }
  return density(a) * (h * sum);
}

function normalCDF(z) {
  const q = tailGauss(Math.abs(z));
  return z < 0 ? q : 1 - q;
}

function simpsonCDF(z, panels = 512) {
  if (z === 0) return .5;
  const a = Math.abs(z);
  if (a >= 39) return z < 0 ? 0 : 1;
  const T = cut(a), h = T / panels;
  let sum = 1 + scaledDensity(a, T);
  for (let i = 1; i < panels; i++) sum += (i % 2 ? 4 : 2) * scaledDensity(a, i * h);
  const q = density(a) * (h * sum / 3);
  return z < 0 ? q : 1 - q;
}

function seriesCDF(z) {
  if (Math.abs(z) > 2) return null;
  const u = z / Math.SQRT2, u2 = u * u;
  let term = u, sum = u, terms = 1;
  for (let k = 0; k < 64 && Math.abs(term) > 1e-17; k++) {
    term *= -u2 * (2 * k + 1) / ((k + 1) * (2 * k + 3));
    sum += term;
    terms++;
  }
  return { value: .5 + sum / Math.sqrt(Math.PI), terms };
}
